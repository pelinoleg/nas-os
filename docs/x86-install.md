# Установка на x86 одной флешкой (Beelink и любой мини-ПК)

_`tools/make-installer-iso.sh` — наш «Raspberry Pi Imager для Debian»._

## Почему это существует
Установщик Debian задаёт ~20 вопросов (зеркала, разметка, tasksel…) — для владельца NAS
это всё шум с одним правильным ответом. Preseed — штатный механизм Debian «файл с готовыми
ответами»; скрипт вшивает его в официальный netinst ISO вместе с юнитом первой загрузки,
который ставит NAS-OS. Получается флешка «прошил → воткнул → ушёл».

## Как пройдёт установка (по шагам, ничего нажимать не надо)
1. Загрузка с флешки → меню, первый пункт «Install NAS-OS (automatic — ERASES the system
   disk)» стартует сам через 3 секунды.
2. Debian ставится по вшитым ответам: язык en, часовой пояс твой, hostname, юзер с твоим
   паролем (root заперт, юзер в sudo), openssh, только standard+ssh (без десктопа).
3. **Выбор диска** — `partman/early_command`: если в машине есть eMMC (`mmcblk*`) — система
   идёт на него; иначе — на САМЫЙ МАЛЕНЬКИЙ диск (на NAS маленький распаянный = система,
   большие = данные). Флешку-установщик из кандидатов Debian исключает сам. **Диск данных
   (NVMe) не трогается вовсе** — они настраиваются потом в панели (или восстанавливаются).
4. Ребут (флешку можно вынуть) → юнит `nas-os-firstboot` тянет `install.sh` с пином
   `NASOS_REF` (лог на экран и в journal, если подключен монитор — видно ход). Условие
   `ConditionPathExists=!/opt/nas-os/nas-web.py` — юнит одноразовый по смыслу.
5. Панель на `http://<hostname>.local`. Если воткнуты диски старого бокса — мастер сам
   найдёт бэкап настроек и предложит «Restore this box».

## Флешка — только на время установки
Да: после шага 4 она не нужна, система живёт на eMMC. Флешку можно стереть или отложить
как «спасательную» на случай следующей переустановки.

## Где собирать
- **Mac (главный сценарий — старый бокс мёртв):** `brew install xorriso`, затем скрипт из
  клона репозитория. Портируемость выстрадана: BSD sed (`sed_i`), `shasum` вместо
  sha256sum, md5-каталог через python, SHA-512-хэш пароля с фолбэками (LibreSSL без `-6`),
  bash 3.2 (позиционные параметры вместо массивов), **MBR-шаблон для гибридного ISO
  берётся из первых 432 байт исходного netinst** — пакет isolinux не нужен вовсе.
- **На самом NAS:** тоже работает (проверено на pi4, там и собран первый ISO) — результат
  положи на шару и прошей с Mac любым прошивальщиком.

## Проверено (2026-08-05, без x86-железа)
Сборка end-to-end на pi4 (941 МБ, checksum netinst сверен); внутри ISO: preseed с нужными
значениями, авто-пункт первым в grub.cfg (timeout 3) и isolinux/txt.cfg (default nasos);
`-report_el_torito` — обе загрузки (BIOS isolinux.bin + UEFI efi.img); `fdisk -l` — гибридная
разметка (EFI-раздел) = флешка прошивается сырым образом. Реальную загрузку до конца
проверит только Beelink — если авто-пункт вдруг споткнётся, в меню остаётся «Manual Debian
install» (обычный установщик), т.е. хуже ручной установки не станет.

## Что подключать и как грузиться (вопрос пользователя «ничего не нужно?»)
Обязательно: питание, **ethernet-кабель**, флешка. Монитор/клавиатура — опциональны, но в
первый раз полезны. Загрузку с USB выбирать **разовым boot-меню** (Beelink: F7 при
включении), НЕ перестановкой порядка в BIOS навсегда: установщик в конце ребутает машину
БЕЗ вопросов, и при постоянном USB-first с воткнутой флешкой бокс загрузит установщик снова
→ тот через 3 секунды снова сотрёт eMMC — цикл переустановки. С разовым F7 безопасно даже
не вынимать флешку: UEFI-запись Debian становится первой, и ребут идёт с eMMC. Либо просто
вынуть флешку через ~15 минут, на ребуте. Ход без монитора: `ping nas.local` с Mac —
ответил → открывай панель (всего ~20–40 мин: Debian → ребут → NAS-OS сам).

## Ограничения
- Установка по КАБЕЛЮ (Wi-Fi в установщике не настраиваем осознанно; в панели — потом).
- Автопункт СТИРАЕТ целевой системный диск без вопросов — это написано прямо в названии
  пункта меню.
